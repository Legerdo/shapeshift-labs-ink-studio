Run Locally or Embed in Your Project

You can install Ink Studio directly from this GitHub fork or clone it locally to sculpt and render scenes:

# Install directly from GitHub fork:
npm install github:Legerdo/shapeshift-labs-ink-studio

# Render a diorama to an image from CLI:
npx ink-studio render watcher --colored --out watcher.png

# Build browser bundles locally:
npm run build
